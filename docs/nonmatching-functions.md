# Nonmatching functions

Every function that is in C but doesn't compile to the original, and the attempts at functions that aren't in C yet. The
addresses are Black 2's and White 2's. `tools/scripts/compiler_probe.py FILE --version b2_us` (and `w2_us`) shows the
difference of each function in a file, and `--show-diff 1.1p1` the instructions.

## In C, not matching

These functions are written as the closest natural C found. Their files are partial (no `complete` in `delinks.txt`), so
the original code is linked until they match. The differences are the same in both versions.

## Keeping this list current

After changing a source file, run `compiler_probe.py` on it for both versions, and add, update or remove its rows. A file
gets `complete` in both versions' `delinks.txt` only when all its functions match and its data is written. The report at
`build/b2_us/report.json` helps find candidates, but its fuzzy match can be below 100 for a matching function because of
relocations, and misses some differences, so the probe decides.
